# 常见问题（FAQ）—— 魔百和 M301H 下载机 + NAS

**Q: 面板打不开（转圈/连不上）？**
A: 开机后服务要 10~30 秒就绪；稍等刷新。确认 `cupsd`…不，确认 `nasd`/`aria2c`/`smbd` 在跑，端口 `8080/6800/445` 通。
   还不行看 `/data/nasstart.log`（应有 `nasstart done: aria2=1 smbd=1 nmbd=1 nasd=1`）。

**Q: 插了硬盘/U 盘，下载没落到盘上？**
A: 约 10 秒后自动切换。看面板「网盘空间」下的「**当前存储**」是否变成「外接盘 …」；否则看 `/root/diskwatch.log`。
   NTFS/exFAT 由脚本手动挂（这 ROM 的 vold 只自动挂 FAT）。

**Q: 拔盘时下载报错？**
A: 正常（文件没了）。拔盘后新任务自动回到内部存储。

**Q: 电脑怎么访问网盘？**
A: Windows「映射网络驱动器」`\\<盒子IP>\nas`；Mac `smb://<盒子IP>/nas`。guest 可读写。

**Q: 磁力/BT 能下吗？**
A: 能。面板支持 磁力 / 种子URL / 直链。⚠️ 子系统网络对 **HTTPS 可能不通**，直链优先用 **http**。

**Q: 盒子屏幕为什么不显示面板 / 按 Home 回了 IPTV？**
A: 这 ROM **硬编码禁止第三方 App 当默认 HOME**，所以只能由开机脚本把面板拉到前台（约开机后 20 秒）。
   按 Home 键会回 IPTV 桌面，属正常。想彻底回原桌面：`pm enable com.zte.iptvclient.android.launcher_ah/com.chinamobile.launcherjs.main`。

**Q: 想换大容量盘 / 固定某块盘？**
A: 直接把盘当外接盘插即可（自动切换）。若要固定 `NAS_ROOT`，改 `smb.conf` 的 path 与启动脚本的 `NAS_ROOT`。

**Q: 怎么改下载目录？**
A: 改 `aria2.conf` 的 `dir=`（默认 `/root/nas/downloads`，会随存储自动切换）。
