# 系统改造手册 —— 魔百和 M301H 变「下载机 + NAS」（深入）

> 目标机：**魔百和 M301H**（创维 CW / 型号 `M301H_CW0_AH` / 海思 **Hi3798MV300** / Android 4.4.2）。

## 总体原理
盒子内 chroot 一个 **Ubuntu 20.04(armhf) 子系统**（`/data/linux`），下载/网盘服务都放子系统里；
Android 侧只负责：开机挂子系统 + chroot 调启动脚本 + 显示面板。**不刷机、不改固件**。

## 分层
| 层 | 内容 |
|---|---|
| Android | 开机钩子（`init.bigfish.sh` 头部）→ 挂子系统 → chroot → 起面板 + ADB 保活 |
| 子系统(chroot) | aria2 / samba / minidlna / nasd / diskwatch |
| 存储 | **自动切换**：外接盘优先（bind 到 `/root/nas`），无盘用内部 |

## 关键数据流
1. 开机 → `init.bigfish.sh` 头部钩子 → `/data/nasstart.sh` → 挂 `/data/linux` → `chroot /root/nasstart.sh`
2. `nasstart.sh` 起 `aria2c`(RPC 6800) / `smbd`+`nmbd`(445/139) / `nasd.py`(8080) / `minidlna` + `diskwatch.sh` 循环
3. 面板 WebView 载 `127.0.0.1:8080`
4. 手机/电脑 → `:8080` 加任务；`:445` 访问网盘

## 存储自动切换（diskwatch.sh）
- 活动存储根恒为 `/root/nas`；有外接盘 → `mount --bind <盘>/nas /root/nas`；无盘 → `umount` 回内部。
- 识别：`/proc/mounts` 里 vfat/exfat/ntfs 且挂载点在 `/mnt/media_rw/*`、`/storage/*`（排除 emulated）；或手动挂未挂载的 `/dev/block/sd*[0-9]` → `/media/usb`。
- 状态写 `/root/nas-active`（面板显示）；日志 `/root/diskwatch.log`。

## 自启（M301H 专属）
- 侧：`/system/etc/init.bigfish.sh`（该文件由 init 的 `bigfish-setup` 服务在 `on boot` 跑）。
- ⚠️⭐ **钩子必须放文件头部**：该脚本末尾的 `/system/bin/wifi_throughput.sh` 是 `while true` 死循环。

## 端口
| 8080 | 面板 | 6800 | aria2 RPC | 445/139 | Samba | 8200 | DLNA |

## 资源与限制
- 老盒子 RAM 小（1G）、USB2.0、多为内部存储 → 只装必要组件。
- ⚠️ 该 ROM **硬编码禁止第三方 HOME**（`ellison. block home apk`）→ 面板只能开机拉到前台。
- ⚠️ 无 `/system/bin/su`；靠串口/adb root。

## 卸载/还原
停服务、卸面板 App（`pm uninstall com.openhardwarelab.desktop`）、还原 `/system/etc/init.bigfish.sh.bak-orig`、删子系统脚本与配置即可（全程可逆）。
