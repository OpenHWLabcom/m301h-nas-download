# 关键坑与经验 —— 魔百和 M301H 变「下载机 + NAS」

> 本机（**创维 M301H / 海思 Hi3798MV300 / Android 4.4.2**）实测踩过的坑。

## 控制 / 系统
- 串口 `ttyAMA0, 115200 8N1`，上电即 root shell（主控制通道）。ADB over TCP：`setprop service.adb.tcp.port 5555; start adbd`。
- ⚠️ `start` 是 `/system/bin/start`（toolbox 符号链接）；**脚本里用绝对路径**。
- ⚠️⭐ **`start adbd` 在 `on boot` 早期时常失败**（时好时坏）→ 开机脚本里**重试 8 次**（每次 sleep 4）。
- ⚠️ 该 ROM **无 `/system/bin/su`**；安卓 shell 无 `printf`/`timeout`；busybox 无 `cp -n`/`grep -x`。

## 开机自启（最大的坑）
- `init.bigfish.rc` 有 `service bigfish-setup /system/etc/init.bigfish.sh`（`on boot`）。
- ⚠️⭐ 该脚本**倒数第 2 行 `/system/bin/wifi_throughput.sh` 是 `while true` 死循环** →
  **钩子必须插在文件"最前面"**（`busybox date` 之后），放末尾永远执行不到。
- 备份 `/system/etc/init.bigfish.sh.bak-orig`。

## 默认 HOME 做不了
- 该 ROM 有 **`ellison. block home apk`**：硬编码只允许内置 IPTV 桌面当 HOME，**第三方 App（含放进 `/system/app` 的系统应用）都不被 HOME intent 解析**。
- → 不能设默认桌面；改为开机脚本 `am start -n com.openhardwarelab.desktop/.MainActivity` **拉到前台**。
- 回滚 HOME：`pm enable com.zte.iptvclient.android.launcher_ah/com.chinamobile.launcherjs.main`。
- ⚠️ 新装 App 处于 `stopped=true`，隐式 intent（含 HOME）不解析 → 先 `am start` 一次。

## 存储自动切换
- ⚠️⭐ **bash 的 `case "$x" in $VAR)` 不会把变量里的 `|` 当分隔符**（实测 literal=Y、var=N）→ 必须写字面量 `vfat|exfat|...`。
- vold **只自动挂 FAT**；NTFS/exFAT 得用 `ntfs-3g` / `mount -t exfat` 手动挂（chroot 装了 `ntfs-3g exfat-fuse exfat-utils`）。
- `/proc/mounts`（chroot 里 = Android 的）用于发现挂载点；未挂载的 `/dev/block/sd*[0-9]` 手动挂到 `/media/usb`。
- 活动根 `/root/nas` 用 `mount --bind` 指向盘的 `nas/`；拔盘 `umount`（失败用 `-l`）。

## 服务
- ⚠️ `pkill -f "<串>"` 会连执行命令的 shell 一起杀 → 用锚定匹配（`[a]ria2c` / `[d]iskwatch\.sh`）。
- 子系统 chroot 里 **apt 可用**（同 CM201-2）；`aria2c -D` 进守护；`smbd/nmbd -D`。
